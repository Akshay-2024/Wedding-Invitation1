# Wedding Invitation Website

A premium animated wedding invitation website designed with elegant glassmorphism UI, floral SVG artwork, smooth scroll animations, countdown timer, RSVP section, floating petals, and ambient music.

## 🌸 Features

- Luxury dark-themed wedding invitation design
- Animated loading screen
- Smooth scroll reveal animations
- Live wedding countdown timer
- Floating flower petal particle system
- Responsive mobile-friendly layout
- Elegant SVG floral decorations
- Google Maps venue integration
- RSVP form with success state
- WhatsApp RSVP button
- Background wedding music toggle
- Modern glassmorphism UI effects

This project can be deployed easily on:

- Netlify
- GitHub Pages

Ensure the main file is named:

